# 软件体积分析与待确认方案

日期：2026-10-23。已先完成代码 Review，本文仅分析，**尚未删除源码、资源或调整打包排除规则**。

## 测量基线

此前已交付的 `dist/pet-visibility-local/` 1.0.3 用于历史对照；本轮改用升级安全内核后的 1.0.4 本地构建进行测量。MiB 按 1024 × 1024 字节计算。下表 1.0.4 数值四舍五入，具体安装包大小以最终生成文件为准。

| 项目 | 1.0.3 历史包 | 1.0.4 安全升级后 |
| --- | ---: | ---: |
| NSIS 安装包 | 90.53 MiB | 最终构建文件另列 |
| 安装后文件合计 | 310.57 MiB | 约 399.7 MiB |
| 主程序 / Electron 引擎 | 180.05 MiB | 224.53 MiB |
| Electron 语言包（55 个） | 40.25 MiB | 47.18 MiB |
| resources（应用代码、依赖等） | 42.62 MiB | 约 42.74 MiB |
| Monaco 编辑器资源（包含在 resources 中） | 13.30 MiB | 13.30 MiB |

新版基础体积增长主要来自 Electron/Chromium 安全升级后的主程序、图形编译库、语言包和第三方许可证，业务代码体积没有相应增长。优化不以回退安全修复为代价。

应用自身的 Electron 主进程代码约 0.26 MiB，Git 同步代码约 0.06 MiB。删除少量业务代码对总体大小帮助有限；优先减少无运行用途的打包内容。

## 推荐第一步：打包精简，保留仓库源码

以下操作均等待用户确认：

| 候选 | 证据与影响 | 预计减少的安装后体积 |
| --- | --- | ---: |
| Electron 仅打包 en-US、zh-CN、zh-TW | 当前 55 个语言包；现有打包器支持 `electronLanguages`。其他语言的系统界面将回退；软件自己的中英文界面继续保留 | 45.54 MiB |
| 不打包旧宣传截图 `assets/`、设计预览 `design/`、开发脚本 `scripts/`、构建入口 `src-vendor/` 和根目录旧展示页面等 | 主界面从 `public/index.html` 加载；这些文件无应用运行引用。源码和设计文件仍留在仓库 | 约 1.7–1.8 MiB |

第一步合计约 **47.3 MiB**，安装后可能从约 399.7 MiB 降至约 352.4 MiB。安装包本身已压缩，不能按该数值直接推算 exe 缩小量，需重新构建后测量。

## 第二步候选：需单独验证

| 候选 | 注意事项 | 体积参考 |
| --- | --- | ---: |
| 将前端用的四个 xterm 包改为开发依赖，避免重复打包 | 前端已从 `public/vendor/xterm/` 加载；保留 vendor 文件和主进程必需的 `@xterm/headless`，并验证干净安装及终端/中文输入/企微交互 | 约 3.25 MiB（迁移前测量，实施前复核） |

这些候选表示打包重复或仅开发用途，不代表整套依赖可以删除。没有识别出可直接整块删除且确定无影响的核心业务模块。

## 本轮不建议精简的部分

- Monaco、Milkdown 都有真实运行入口，分别服务代码编辑和 Markdown 编辑；不能按“体积大”认定无用。
- 保留离线用户指南（约 2.64 MiB），避免删去刚补充的使用说明。
- 保留 Electron 图形渲染、视频解码等运行文件及第三方许可证；不通过删除必要组件换取不稳定运行。
- `dist/` 已排除在发布包之外。历史构建与测试文件曾合计约 7.1 GiB，其中 `test-data` 约 3.9 GiB（后续验证还会增加）；清理历史构建只释放开发电脑磁盘，不缩小发布的软件；需要另外明确保留哪些安装包后再清理。
