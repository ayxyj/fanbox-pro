# SSH 与 AI 工作台

左侧 **SSH 连接 → 会话管理** 点击展开会话树；先显示分组，再显示组内会话。单击会话连接或切换已连接终端，右键可打开 AI 会话、远程文件、编辑或删除。窗口左上角菜单栏顺序为 **文件 → 编辑 → 视图 → 窗口 → 设置**，在设置中打开 AI 配置。工作台与终端左右并排，可拖动中间分隔条调整宽度；关闭工作台不会断开终端或停止任务。

## SSH 连接

左侧「SSH 连接 → 会话管理」旁的 + 打开分类设置弹窗。常规页填写认证信息，连接 / 代理页设置跳板和代理，AI 权限页设置连接默认权限。

新建连接时，填写主机、端口、用户名及密码或私钥路径。支持分组、搜索、编辑、删除、多标签连接。断开后的终端按回车可重新连接；关闭标签会断开连接并取消对应传输。

- 提供密码或保存的凭据时直接连接；无密码时终端显示 `password:`，输入不回显，回车提交。密码被拒绝后提示认证失败并重新等待输入，不会自动把错误密码再提交给另一种认证方式；单次连接最多 3 轮认证，服务器可能更早断开。重输的密码仅用于当前连接，不自动覆盖已保存凭据。Ctrl+C 取消认证；私钥口令、服务器多因素认证也在终端输入。认证输入不进入 AI 输出缓存。
- 密码默认仅在本次进程内保留。勾选记住后，密码、私钥口令及代理密码由 Electron `safeStorage` 加密保存。私钥本身不复制到配置文件。
- 首次登录需核对主机 SHA256 指纹；指纹变更时重新确认。跳板机与目标主机分别验证。
- 跳板机选择已保存的连接，可嵌套至 5 层，循环配置会被拒绝。
- 支持 SOCKS5 和 HTTP CONNECT 代理及用户名密码认证。经跳板机连接时，将代理配置在最外层跳板连接上。
- 远端通过独立只读探测识别 Linux / macOS / BSD、默认 Shell 和初始目录。识别失败仍可人工使用终端，但 AI 独立执行会被阻止。
- SSH 标签使用连接名称显示，双击标签进入远程文件，不会导航到本机同名路径。

## 远程文件

在「远程文件」中选择已连接的 SSH 会话，双击文件夹进入下一层，双击文本文件编辑；顶部完整路径按层可点击返回，上级目录使用 ↑ 图标。可上传下载、查看传输进度、取消和重试。列表每页 200 项，避免大目录导致界面卡顿。

2 MB 以下 UTF-8 文本支持编辑。保存前确认目标主机与路径，并通过大小、时间及内容摘要检查外部修改。上传和编辑先写入临时文件，再重命名为目标文件；不支持覆盖重命名的 SFTP 服务可能拒绝覆盖，此时保留原文件并报错。取消时尽力清理临时文件；连接中断时远端可能留下 `.fanbox-*` 临时文件。

传输重试会重新选择本地文件，避免自动覆盖用户后来修改的本地路径。二进制及其他编码文件建议下载后使用对应编辑器处理。

## AI 模型与权限

菜单栏「设置 → AI 配置」独立管理多套模型配置，每套包括名称、协议、地址、模型及加密密钥，列表中启用其中一套。已启用配置显示「停用」，其他配置显示「启用」；停用状态会保存，编辑未启用配置或删除当前配置不会自动启用其他配置。未启用任何配置时不能发起新 AI 任务；切换与停用对新任务生效，已有任务仍可在聊天页停止。旧单模型配置自动迁移。更换地址或协议必须重新输入密钥或清除旧密钥，避免误发给其他服务。

- OpenAI 兼容：Chat Completions 与 function tools，基础地址通常为 `https://example.com/v1`。
- Anthropic / Claude：Messages API、`x-api-key`、`anthropic-version`、`tool_use` / `tool_result`，基础地址可为 `https://api.anthropic.com` 或含 `/v1`。
- 支持 HTTPS 服务及本机 HTTP 服务。密钥只在主进程读取，不返回界面；启用配置应用于下一轮任务。

右键终端标签或会话管理中的已连接会话，选择「打开 AI 会话」。左侧顶部是可切换的多个会话标签，中间展示各自聊天记录，底部为消息输入和图标按钮；右侧保留对应终端。输入框的选项菜单提供执行权限、交互开关、终端上下文授权、接管及清空对话。不同终端可各自运行 AI 任务，停止按钮只作用于当前会话。Enter 发送、Shift+Enter 换行；支持停止、接管、新对话，切换终端同步切换对应聊天。

权限在主进程执行检查，默认确认后执行，可在 SSH 连接设置默认值，也可在聊天页针对当前终端即时覆盖（不随重启保存）：

| 模式 | 行为 |
| --- | --- |
| 仅读取 | 提供建议，无命令执行工具；即使模型自行返回工具调用也会拦截 |
| 确认后执行 | 每条命令展示机器、系统、Shell、目录和原文，确认后执行 |
| 自动执行 | 允许在选定目标执行命令，包括修改文件或系统；仅用于信任的任务 |

「允许 AI 使用交互式终端」为独立开关，默认关闭。开启后，交互输入仍逐次确认实际目标及前台程序。手动 `ssh`、容器登录等会改变前台环境，不能仅凭终端提示符推断，用户确认是发送输入的必要条件。

AI 命令直接写入右侧已连接的 SSH shell 或本地 CMD / PowerShell 终端，不再另开独立执行进程。当前目录和环境变量沿用该终端的状态。所有命令和输出在右侧查看；左侧仅显示用户消息、AI 简要操作说明及「执行的命令」标记，不复制工具输出或退出码。用户消息在右侧、AI 回复在左侧，支持流式文本；模型服务返回的分析内容显示在可折叠的「思考 / 分析」区域，没有返回分析时只显示实际任务进度，不编造思考过程。

输入框旁直接显示当前权限：仅聊天、确认后执行或自动执行，点击可展开权限选项。未开启交互权限、仅建议模式或模型未调用终端工具时，会明确提示本轮未执行命令。流式工具参数接收完整后才执行；响应截断或未正常结束时不会执行不完整的工具调用。

执行命令和发送交互输入都需要开启「允许 AI 交互式终端」。仅建议模式不提供执行工具；确认模式逐条确认，自动模式按授权执行普通命令。执行前应让终端停在 Shell 提示符；未提交的输入会阻止 AI 命令。检测到手动 SSH / 容器切换时暂停执行，需选择对应的 SSH 目标，避免向错误主机发送命令。

常规命令使用现有 shell 的完成标记检测结束，支持 POSIX sh/bash/zsh/dash/ksh、PowerShell 和单行 CMD；CMD 不报告可靠退出码。每轮最多 10 次模型请求，模型获取的结果最多保留 64,000 字符。超过 60 秒仍保持监听，显示耗时及输出状态；超过 5 分钟提醒一次，不重复执行、不自动结束命令，收到完成标记后继续。疑似密码或确认提示仅提示用户查看，不自动提交答案。常驻程序优先使用有限观察或合适的后台运行方式；无法收到标记时可手动接管。

「停止命令」发送 Ctrl+C，最多等待 10 秒确认；未收到完成标记时明确告知结束状态未知。「接管终端」不发送中断，保留命令监听并暂停 AI 后续操作；点击「让 AI 继续」重新检查目标、权限和未提交输入，仍在运行的命令继续等待，不重新执行，后续命令需要重新确认。切换聊天不影响任务监听，后台会话结束后显示标签提示。终端连接断开会停止监听并报告结果未知，不宣称远端进程已被终止。

只有勾选「允许本轮发送终端最近内容」时，才在初始请求中附加终端内容；AI 执行命令的输出及获准交互后的输出会发送给配置的模型服务供后续判断，但不复制到左侧聊天显示。SSH 密码、私钥、代理密码不作为模型上下文。同一运行中终端保留短期上下文及结果摘要。

会话记录以本地 JSON 文件保存在配置目录的 `ai-conversations` 中，包括用户消息、AI 回复、服务返回的分析及执行命令标记，不保存终端原始输出、认证密码或 API 密钥。聊天顶部的「会话历史」文字按钮及菜单栏「设置 → 会话历史」可查看所有记录、删除或继续对话；新建对话会保留原有历史。每个终端独立绑定一段对话，新终端默认空白对话，即使连接相同服务器或使用相同 Shell 也不共享。一段历史不能同时绑定两个终端；可在原终端继续，或关闭原终端后手动恢复。SSH 历史校验连接 ID、主机、端口和用户名，本地历史校验机器和 Shell。恢复上下文只选取最近用户和 AI 文本（最多 12 条、48 KB），不恢复旧工具调用、执行权限或运行任务。旧版本未保存的聊天无法追溯恢复。消息列表默认展示最近 100 条，可加载更早消息；输入框始终处于聊天区域底部，消息区独立滚动。

配置文件为配置目录下的 `remote-workspace.json`。`shell-ai-audit.jsonl` 记录时间、目标、动作类型及批准结果，不保存命令正文、密码或输出；超过 2 MB 轮换为 `.previous`。

## 验证

- `node tests/remote-workspace.integration.js`：本地 SSH 测试服务、SFTP、跳板机、代理、加密存储、模型权限与本地执行。
- `node tests/remote-workspace-ui-smoke.js [exe路径]`：独立 Electron 测试配置、SSH 标签、界面设置、模型聊天、Windows 环境和 SFTP 会话隔离。
- `node tests/terminal-command.js`：现有终端写入、回显与完成标记区分、分片和大输出、长期监听、一次性提醒、Ctrl+C 确认及断线清理。
- `node tests/shell-ai-long-running.js`：接管不终止命令、完成后暂停、恢复前校验、不重复执行与断线清理。
- `node tests/chat-history.js`：重启恢复、多个对话、目标隔离、历史上下文、任务中断及删除。
- `node tests/model-api.integration.js`：旧配置迁移、多配置切换和密钥隔离，两种协议的请求、认证头及工具结果转换。
- `node tests/model-stream.integration.js`：两种协议的 SSE 分片、中文解码、分析和文本增量、工具参数拼接、签名保留及截断拒绝。
- 测试使用本机模拟模型，无需真实 API 密钥，不会调用付费模型。

实现依据：[ssh2 客户端与 SFTP 文档](https://github.com/mscdex/ssh2)、[SOCKS 客户端文档](https://github.com/JoshGlazebrook/socks)。

API 格式依据：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Anthropic 工具定义](https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools)。
