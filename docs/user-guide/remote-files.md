# 远程文件与传输

远程文件使用当前 SSH 连接的 SFTP 能力。能打开 Shell 不等于服务器一定允许 SFTP；堡垒机需同时允许文件传输。

## 浏览与返回上级

1. 先连接目标 SSH 会话。
2. 在会话的右键菜单中打开“远程文件”，或在 AI 会话选项中打开。
3. 检查页面上的连接目标，确认当前操作的是正确服务器。
4. 双击文件夹进入下一层。
5. 点击上方路径的某一段返回对应目录，或使用上级目录箭头。

目录按页显示，每页最多 200 项。大目录先翻页或进入子目录，不要把第一页误认为全部文件。

## 编辑远程文本

双击支持的文本文件进入编辑，修改后点击“保存到远端”。当前支持小于 2 MB 的 UTF-8 文本；二进制或其他编码文件建议下载后处理。

保存时会检查文件是否被其他程序修改。遇到冲突提示，先保留你的修改，再重新读取远端内容做比较，不要反复强制覆盖。

## 上传、下载、取消和重试

使用远程文件页面的上传 / 下载操作，按系统文件选择框选择本地源或目标路径。传输区域会显示状态、已传字节和进度。

- **取消：**中止当前传输；连接断开时可能留下临时文件。
- **重试：**重新选择本地文件或保存位置，避免无意覆盖后来更新的文件。
- **覆盖失败：**部分 SFTP 服务不支持所需的覆盖重命名操作，原文件会保留，应按错误提示处理。

## 与企微发送文件的关系

远程文件下载与企微附件发送是两步：先下载到运行 FanBox 的 Windows 电脑，再让 Agent 把本地文件发送到当前企微会话。不能把 `/home/demo/report.md` 这样的远端路径直接当作 Windows 本机文件发送。

本章没有使用真实服务器截图；入口与步骤以当前实现为准，避免将本地文件浏览截图误标为 SFTP 页面。

## 在 SSH 终端使用 rz / sz

内置 SSH 会话支持 ZMODEM 文件传输，使用当前 Shell 通道，不要求另开 SFTP。远端需要提供 `rz` / `sz`（通常来自 lrzsz）；堡垒机也需允许该协议通过。

- **Windows 上传到 SSH：**在远端终端输入 `rz` 并回车，弹出的文件选择框可选择一个或多个 Windows 文件。文件写入远端当前目录；覆盖行为由远端 rz 参数决定。
- **SSH 下载到 Windows：**输入 `sz 文件名` 并回车，例如 `sz report.txt`，在 Windows 保存对话框中选择目标位置。多文件会逐个选择保存位置。
- **进度：**终端显示文件名、已传字节和完成状态。
- **取消：**传输时按 Ctrl+C；取消上传文件选择也会中止传输，取消下载保存框则跳过该文件。
- **异常：**连接断开或连续两分钟没有传输进展会取消。下载先写临时文件，完整接收后才替换目标文件；失败时保留原目标文件。上传失败后的远端残留由远端 rz 处理。

每个文件必须小于 4 GB，不支持断点续传。传输期间请等待结束再输入其他命令。此功能适用于从“SSH 链接”打开的内置 SSH 终端；在本地 CMD / PowerShell 中手动运行 ssh.exe 不属于该通道。
