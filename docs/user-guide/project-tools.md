# 项目工具与进阶编辑

## Markdown、表格与差异

Markdown 文件提供预览 / 编辑能力，按编辑器提供的切换入口使用富文本或源码方式。保存前检查实际文件内容，尤其是包含复杂表格或特殊语法的文档。

CSV / TSV 等文本表格可按支持情况以表格预览。代码与文本文件的差异查看依赖该文件的 Git 状态；在预览操作区出现差异入口时可打开对照。

## 图片标注与导出

打开图片后，在预览操作区选择编辑，可使用自由画笔、矩形、直线、箭头、文字和打码工具。颜色、笔画粗细和撤销位于编辑工具栏。

完成后选择 PNG、JPEG 或 WebP，按需调整宽度及有损格式质量。**保存会修改目标文件；希望保留原图时使用另存为。** 编辑完成后再复制或发送图片，避免把尚未保存的画布误认为磁盘上的最新文件。

## 项目记忆与内置会话历史不同

在当前目录底部状态栏点击“项目记忆”，查看已发现的 Claude Code / Codex 项目会话日志、涉及文件和使用记录。展开记录可查看关联文件；点击文件进入相应位置。

“续上”会在终端启动对应 CLI 的历史恢复命令，不是把 CLI 历史导入内置 AI。当前本地调试包中的 Claude 恢复入口使用 `--permission-mode auto --resume 会话ID`，由 Claude 判断操作权限；实际模式以终端显示为准。需要手动审批时，可在终端运行 `claude --permission-mode manual --resume 会话ID`。

没有发现记录时页面会显示空状态。删除或迁移外部 CLI 日志会影响可见历史，FanBox 不保证能恢复所有外部工具的旧对话。

## 占用透视

从目录底部“占用透视”或文件夹右键菜单打开，查看包括子目录在内的磁盘占用。点击目录行可以下钻，适合定位缓存、构建产物或大文件。

大目录扫描可能需要时间，文件权限和扫描口径会影响结果。先定位实际路径，再使用文件管理操作处理；不要仅因为文件大就删除依赖或工作文件。

## AI 整理目录

目录菜单中提供 AI 整理入口时，可把当前目录交给已安装的 Agent 讨论整理方案。软件会准备目录约定和历史资料，并在终端启动对话。

先核对待移动文件与目标位置，再让 Agent 执行；整理可能影响脚本路径、引用和工程结构。撤销需结合整理日志与实际文件状态处理，不要把所有文件移动都当作可无条件恢复。

## 发版向导

检测到项目时，底部状态栏可能显示“发版”。打开后核对当前版本、目标版本和发布说明，并选择界面提供的打包、推送或 Release 选项。

点击“在终端开跑”后，操作序列在终端执行。当前工作区未提交改动可能一并进入发版提交，务必先检查变更范围。构建命令由项目自身脚本决定，不保证所有项目都会生成 Windows exe；不要照搬其他平台的打包脚本。

推送与发布会影响远端仓库，先确认分支、远端地址和权限。某一步失败时根据终端输出处理，不要因界面已关闭就认定发布完成。
