# 常见问题与排查

## AI 配置与聊天

| 现象 | 先检查 | 下一步 |
| --- | --- | --- |
| 获取模型失败 | HTTP / HTTPS、主机、端口、路径、网络 | 使用服务实际地址；再用“检测”验证具体模型 |
| HTTP 401 / 403 | 密钥、账户权限、网关认证方式 | 重新填写对应密钥，确认该模型可用 |
| fetch failed / 模型连接失败 | 地址协议、证书、网络可达性 | 查看新版具体错误；不要把 HTTP 服务误配成 HTTPS |
| 模型检测成功，但不执行命令 | 交互开关、权限模式、工具调用支持 | 开启交互并选择确认模式，发送明确执行任务 |
| 目标系统未识别 | 是否还在登录菜单 / 堡垒机选择界面 | 先人工进入 Shell，再让 AI 识别；必要时确认实际系统 |
| 模型长时间无响应后中断 | 是否连续 5 分钟无新数据 | 检查模型服务；继续前核对已执行命令 |
| 继续任务却像重新开始 | 是否换了终端 / 新对话 / 旧版本 | 使用新版，在原会话继续；重述最新目标与已完成事项 |
| 命令没有结束 | 是否常驻程序或等待交互 | 查看终端，接管或停止，不要重复启动 |

## SSH

`All configured authentication methods failed` 通常与认证相关。先检查用户名、密码 / 私钥和服务器允许的方法。密码留空时应在终端等待输入；密码错误后应重新输入，不要在聊天输入框发送密码。

齐治终端显示 `Please re-login` 时，优先核对终端类型 `xterm`、系统探测选项以及堡垒机要求的登录流程。先保证人工 Shell 能稳定登录，再启用 AI。

远程文件打不开而 Shell 可用时，检查 SFTP 权限和堡垒机文件传输能力。

## 企业微信

1. 在 IM 设置检查是否启用、是否连接、有无错误。
2. 检查发消息的账号是否已绑定。
3. 检查“允许已绑定账号操作终端”是否开启。
4. 用 `/list` 核对当前会话；切换到正确项目。
5. 内置 AI 检查启用模型；CLI 检查终端是否已经启动、登录或等待确认。

“凭据无法解密”：重新扫码或填写 Secret；AI 密钥也可能需要重新填写。不要把秘密值发到问题反馈中。

“已批准；卡片更新失败”：决定已记录，只是卡片状态更新失败。等待执行结果或查看终端，不要重复批准旧卡片。

“无法确认终端前台进程”：查看本机终端是否仍在启动 / 信任提示 / 登录界面，处理后重试。消息被拦截是为了避免 CLI 退出后把普通文本作为 Shell 命令输入。

| 现象 | 当前行为与处理 |
| --- | --- |
| Claude 一次提出多道问题 | 企微只发送当前聚焦的一题；回答并确认终端进入下一题后，再发送下一题。不同终端各自独立 |
| 同一问题看起来有两条消息 | 一条是详细说明，一条是可点击卡片；不表示有两道待回答问题 |
| 选择后终端仍停留在原问题 | 查看是否收到“尚未确认生效”；不要重复点击旧卡片，发送 `/retry` 获取当前问题，或在本机处理 |
| 问题卡片过期或发送失败 | 每题分别有 4 分钟回答时间；可用 `/retry` 重新获取当前菜单，卡片失败时也可按文字提示回答 |
| 多会话中回复到错误项目 | 先用 `/list`、`/sel 编号` 核对；指定问题可用 `/回答 问题编号 内容` |
| 启动后没有进入 auto | 先退出旧 Claude，再通过 `/claude` 启动；核对 CLI 版本、模型支持与组织策略，以终端显示为准 |

确认反馈以终端实际变化为依据，短暂清屏不作为成功。自动化测试覆盖逐题发送、按键回传及旧卡片失效，真实账号的网络与权限问题仍需在线检查。

## 宠物

机器人能发消息但宠物不动，不代表机器人离线。检查宠物“启用动画”；新版手动播放不受 Windows 减少动态效果限制。若仍看到旧版“当前离线或已关闭动画”提示，退出旧实例并启动新版本。

主窗口最小化后宠物应继续显示；如果被隐藏，从 IM 设置恢复。单击桌面宠物可唤出软件。

右键可打开设置、左键却无法拖动时，优先点击“重置位置”。当前本地调试包会同时清理拖拽状态并刷新窗口交互区域，保留所选大小。也可切换一次大小后再试；仍无效则保存工作并重启软件。这是手动恢复，没有后台定时检测和自动刷新。具体操作见[桌面宠物](appearance.md)。

## 文件与界面

HTML 空白：先确认文件能被浏览器打开，检查外部资源、相对路径和是否必须启动开发服务器。不要将所有 HTML 都当作无需服务的静态页面。

文件保存失败：检查路径权限、只读状态以及外部文件修改。远端文件冲突先比较版本。

终端中文无法输入：先确认焦点在终端、输入法正常，候选词选定后再提交；使用最新版本的输入法兼容修复。

## 反馈时提供什么

提供版本、出问题的入口、操作顺序、完整错误文字、发生时间，以及不包含密钥的截图。说明是本地终端还是 SSH、内置 AI 还是 CLI、滚轮滚动还是调整终端尺寸。不要上传密码、Secret、API 密钥或完整私钥。
