# 数据、备份与快捷操作

## 数据保存在哪里

默认业务配置目录为 Windows 用户主目录下的 `.fanbox-pro-win`，例如 `%USERPROFILE%\.fanbox-pro-win`。配置了 `GITSYNC_HOME` 时，业务配置位置会随之变化。

| 内容 | 保存范围 |
| --- | --- |
| SSH / AI / IM 等业务设置 | 业务配置目录；具体设置保存在相应配置文件中 |
| AI 聊天历史 | `ai-conversations` 子目录 |
| 执行审批审计 | `shell-ai-audit.jsonl`，不含命令正文和原始输出 |
| 主题、宠物等界面偏好 | 应用本地浏览器存储 |
| 桌面宠物位置 | Electron 用户数据目录 |
| 项目代码、文档、下载文件 | 原来的文件目录，不会因聊天记录删除而删除 |

密钥和记住的凭据使用系统加密。把配置复制到另一 Windows 用户或另一电脑后，密文可能无法解密，需要重新输入凭据或扫码；仅有配置备份不保证密钥能跨机器恢复。

## 备份和迁移建议

1. 保存编辑内容，停止任务并退出程序。
2. 备份项目文件和业务配置目录。
3. 如需保留外观等偏好，同时备份对应 Electron 用户数据目录；实际位置以当前安装环境为准。
4. 在目标电脑安装 CLI、Git 等外部工具并重新登录。
5. 恢复配置后逐项测试 SSH、模型和企微连接；无法解密的凭据重新配置。

聊天历史不能恢复已经结束的终端进程。不要用直接编辑历史 JSON 的方式恢复执行授权。

## 常用快捷键与入口

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 文件搜索 | Ctrl+K |
| 搜索范围切换 | 搜索框内 Tab |
| 文件重命名 | 文件区域 F2 |
| 保存文本 / 代码 | 编辑器 Ctrl+S |
| AI 发送消息 | Enter |
| AI 输入换行 | Shift+Enter |
| 中断终端前台任务 | Ctrl+C，实际行为由前台程序决定 |
| Claude 权限模式循环 | Shift+Tab，或支持的权限图标 / 企微 `/permiss` |
| 查看会话历史 | 当前 AI 会话顶部“会话历史” |
| 弹窗取消 | 取消 / 关闭；支持的弹窗可按 Escape |

快捷键具有焦点范围：编辑器、终端、搜索框中的相同按键可能有不同含义。中文输入候选状态下先完成选词。

## 信息会发到哪里

内置 AI 将你的消息及获准的上下文发送给已配置模型服务；执行工具得到的结果也用于后续分析。企微桥接发送消息和所选附件给当前绑定账号。CLI 使用自身的服务配置。

“本地文件浏览”与“调用在线 AI / 企业微信”应区别理解：不要把界面上的本地运行说明理解成所有功能都完全离线。
