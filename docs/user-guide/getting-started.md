# 安装与快速开始

## 1. 安装或运行

安装版文件名形如 `fanbox-pro-1.0.1-x64.exe`。双击后按安装向导选择安装目录，安装完成后从桌面快捷方式启动。

如果使用 `win-unpacked`，保留整个文件夹并运行其中的 `fanbox-pro.exe`。不要只复制 exe，旁边的资源和依赖文件也是运行所必需的。

更新前保存正在编辑的文件，并结束不需要保留的终端任务。退出旧版后再启动新版，避免后台旧实例让你看到的仍是旧界面。关闭终端或退出软件可能中断 SSH / CLI 会话。

## 2. 认识工作界面

![工作界面与目录树](assets/01-workspace.png)

*左侧负责导航，上方显示路径和视图切换，中间是文件区域。*

| 区域 | 操作 |
| --- | --- |
| 左上角菜单 | 文件、编辑、视图、设置；AI 和 IM 配置位于设置中 |
| 快速入口 | 打开主目录、桌面、文档、下载等路径 |
| 一级菜单左侧三角 | 展开 / 折叠该模块；默认仅快速入口展开 |
| 路径导航 | 点击上级路径段返回对应目录 |
| 右上角视图按钮 | 切换目录树、网格、列表；后续启动沿用用户选择 |
| 终端按钮 | 在当前目录打开本地终端 |
| 文件区 / 预览区分隔线 | 拖动调整显示宽度 |

## 3. 完成第一次本地操作

1. 从快速入口找到一个测试项目目录。
2. 切到目录树，展开文件夹，点击一个文本文件。
3. 在编辑器中修改内容，用 `Ctrl+S` 保存。
4. 点击“终端”，确认提示符中的目录是目标项目。
5. 在 PowerShell 输入 `Get-ChildItem`，或在 CMD 输入 `dir`。

**完成标志：**文件能保存，终端列出对应目录的内容。此流程不依赖 SSH、模型密钥或企业微信。

## 4. 按需要配置扩展能力

- 连接服务器：先添加 [SSH 连接](ssh.md)。
- 使用内置 AI：先创建、测试并启用 [AI 配置](ai-settings.md)。
- 使用 CLI：先在电脑上安装并登录相应 CLI，再从 [终端](terminal.md) 启动。
- 手机远程操作：先完成 [企业微信绑定](wecom-setup.md)。

## 常见启动问题

启动后没有新窗口，先检查任务栏和后台是否已有实例；桌面宠物仍显示时，可以单击宠物唤出主窗口。若新版包不完整，重新解压完整文件夹后启动，不要从压缩包内直接运行。
