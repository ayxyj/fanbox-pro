# 自定义宠物动作与皮肤

点击应用右下角宠物，展开“皮肤与自定义动作”。导入内容保存在当前应用的本机用户配置中，不上传服务器。

## 动作

修改 `street-dance.json`，再点击“导入动作”。也可在宠物面板下载街舞示例。

- `version`：目前为 `1`。
- `name`：1–40 字符。
- `duration`：单轮时长，200–15000 毫秒。
- `iterations`：重复次数，1–3。
- `keyframes`：2–60 个关键帧；`offset` 从 0 递增至 1，首尾必须是 0 和 1。
- `x`、`y`：-25 至 25，宠物 100×100 坐标系内的位移。
- `rotate`：-180 至 180 度。
- `scale`：0.6 至 1.4。

动作控制宠物整体的位移、旋转和缩放，不包含骨骼或逐帧动画。仅接受数据，不运行 JavaScript、CSS 或外部命令。离线、状态未知、关闭动画或系统要求减少动态效果时，不播放自定义动作。

最多保存 20 个自定义动作，每个文件不超过 32KB。删除内置动作不可用。

## 皮肤

每种宠物提供原色、奶油、夜空、薄荷配色。自定义皮肤可使用：

1. 配色 JSON：参考 `mint-skin.json`，`fur`、`outline`、`muzzle` 分别为主体、描边、口鼻部位颜色，格式为 `#RRGGBB`。
2. PNG / WebP 图片：建议透明背景，最大 512×512，文件不超过 256KB。图片作为整个宠物外观，仍支持整体动作与离线睡眠变换，但不会自动生成闭眼或关节动作。

最多保存 8 个自定义皮肤。皮肤与动作可组合使用。

机器人错误详情、最近收发时间和连接记录在宠物详情中查看。宠物显示在线不代表远程执行已授权。凭据无法解密时，需要在 IM 设置中重新填写 Secret 或重新扫码。
