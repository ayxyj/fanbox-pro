## 2026-10-14 终端修订

普通历史缓冲区滚轮通过 xterm 公共 API 直接更新逻辑显示行，再由引擎同步滚动条和渲染；移除滚轮触发的强制跳到底部。保留触控板的小数增量、滚动灵敏度、Alt 加速、备用屏幕和应用鼠标协议。xterm 5.5 的 DOM 优先滚动路径存在程序同步后忽略下一次滚动事件的边界，可能重复显示同一屏；测试主动模拟该边界。

原生 PTY 清除启动器继承的 `NO_COLOR`，声明 `TERM=xterm-256color`、`COLORTERM=truecolor` 和 `CLICOLOR=1`。从命令环境启动时观察到 `NO_COLOR=1`，这会让遵循该变量的 CLI 主动关闭颜色。已有终端进程需要重新创建才能使用新环境。

- `node tests/terminal-scroll-color-smoke.js`：真实 PowerShell 环境、16 色/256 色/RGB 单元格属性；6500 行唯一编号、24 次原生向上滚轮、历史无重复写入、持续输出时保留阅读位置，以及备用屏幕与鼠标协议。

## 保留的边界

主进程沿用原有原生 PTY 输出时机。尝试改变这一时机时，辅助 PowerShell 会话回归出现等待，因此最终采用渲染侧批处理；没有替换终端引擎。

大型编辑器和静态资源继续保留按需加载。`app.js` 仍承担大量功能，本次把目录树和终端消费队列独立成模块；后续可逐步拆分预览、文件跟随和布局逻辑，但仅拆文件不能直接解决运行时卡顿。

以上数字是测试场景中的结果，不代表所有仓库和 CLI 的帧率。Git hooks、磁盘速度和网络仍可能使操作耗时；界面会显示实际阶段与耗时。
