# 企业微信远程终端

入口：设置 → IM 远程干预与通知。

1. 点击“扫码创建机器人”，使用企业微信扫码确认。二维码有效期 5 分钟。也可以展开手动凭据，填写已有智能机器人 Bot ID / Secret。
2. 给机器人发送一条私聊消息，在电脑端确认并绑定接收账号。
3. 选择工作目录、CMD / PowerShell，以及 AI 对话或 Claude / Codex / CodeBuddy CLI 模式，开启“允许已绑定账号操作终端”并保存。
4. AI 模式使用“设置 → AI 配置”中已启用的模型；命令默认通过企微逐次确认。点击卡片上的“批准 / 拒绝”，5 分钟内有效。点击后卡片显示决定，重复点击不会重复执行；旧版文本审批命令仍兼容。
5. `/帮助`、`/状态`、`/停止` 可查询或请求停止。AI 长任务沿用终端结束标记监控，不因短期无输出判定完成。

每个账号可新建多个独立终端，账号之间隔离；直接发送消息会续聊该账号当前聚焦的会话，结果私聊回复发送者。重复 msgid 不会重复执行。关闭连接、撤销授权或解绑账号会取消待确认操作并停止 AI 后续执行；已经运行的外部进程是否结束以终端实际状态为准。

CLI 需提前安装、登录。`/claude`、`/codex`、`/codebuddy` 在绑定的真实终端写入启动命令，显示原生交互界面。普通消息使用括号粘贴原样传给 CLI 后提交，不经过内部 AI 分析。进入其他 CLI 前先退出当前程序。CLI 自身权限保持生效。

`/aiquit` 向终端发送 Ctrl+C（必要时再次发送），检测到空闲 shell 才恢复 AI 对话；仍在运行时保留 CLI 模式。每次发消息前检查实际进程，避免 CLI 退出后把消息当作系统命令执行。本地键盘输入始终直达 PTY。通过会话独立的完成通知发送最终回复：Claude Stop / StopFailure，Codex notify，CodeBuddy Stop。回调按事件去重，不发送 PTY 重绘、动画或输入回显。设置仅通过当前进程的 --settings / -c 载入，不修改全局配置。通知辅助程序需要 PATH 中的 Node.js。限流重试只提示一次，未收到完成事件不会把静默当成功。`/content` 可查看最近内容。CLI 模式下 `/help` 交给 CLI，`/bridge` 查看桥接帮助。


机器人 Secret 使用 Electron safeStorage 加密，只在主进程解密；二维码查询结果中的凭据不传给网页。账号绑定在本机确认。修改连接或执行方式会结束现有远程路由；下次消息创建新终端，原终端的 AI 历史保留。会话历史只在对应会话中展示，使用表格，不在顶层设置菜单中展示。

## Code Chat 命令

- /claude、/codex、/codebuddy：快捷进入指定 CLI；无需单独选择默认模式。
- /aiquit：发送 Ctrl+C，确认 CLI 退出后恢复 AI 对话。

- /projects [页码]：列出配置工作目录的直接子目录（含指向目录的链接），每页 20 个；显示当前路径及可复制的 /new 命令。支持中文别名 /项目。
- /new [项目名]：新建并聚焦终端。省略项目使用配置工作目录；项目名表示其子目录，也支持完整目录路径。目录须已存在。
- /list：列出自己的当前会话，包含编号、完整会话 ID、项目及状态。编号在当前软件进程中不重用。
- /sel 编号|会话id：切换聚焦，不中止原会话的后台任务。
- /content：读取聚焦终端最近输出；是快照，不代表命令已结束。
- /set_name 英文名 中文名 [昵称]：首次保存身份；修改需追加 --force。身份持久保存，仅用于称呼，不改变权限。
- /help：帮助。兼容 /帮助、/状态、/停止。

每条文本推送采用简洁标题及 [会话:短ID] 标记，旧版 [CodeChat:会话ID] 引用仍兼容。引用推送并发送文本可切换到原会话；不存在、关闭或他人会话的引用不会回退到当前会话执行。切换焦点后，原任务的审批和结果仍归原会话。/list 只展示当前进程中仍打开的桥接终端，程序重启不会自动重新执行任务。

## 协议来源

- [企业微信官方文档](https://developer.work.weixin.qq.com/document/path/101805)
- [官方 Node SDK](https://github.com/WecomTeam/aibot-node-sdk)：长连接订阅、心跳、重连、消息收发。
- [官方 CLI 二维码实现](https://github.com/WecomTeam/wecom-cli/blob/main/crates/wecom-cli/src/auth/qrcode.rs)：`https://work.weixin.qq.com/ai/qc/generate` 和 `https://work.weixin.qq.com/ai/qc/query_result`，使用官方 CLI 的 `wecom_cli_external` 来源参数。这是官方开源客户端采用的流程，服务端若调整接口或来源准入，需同步适配；手动填写凭据可独立使用。

## 验证

`node tests/cli-session.js` 验证 stdin 原文、会话 ID 续聊、完成事件与退出码双重确认、取消及隔离。

`node tests/wecom-service.js` 使用模拟服务验证绑定、隔离、去重、审批、撤权、CLI 检测及扫码凭据处理，不创建真实机器人、不发送真实消息。

`node tests/remote-workspace-ui-smoke.js` 验证桌面设置页面、历史表格恢复及既有 SSH/AI 交互。真实扫码、企业账号权限和 Claude CLI 回传需要实际账号联调。

Claude 首次显示工作目录信任确认时，企微发送“信任目录 / 不信任，退出”卡片，显示实际目录。拒绝或超时请求退出，等待期间不转发聊天消息；本机键盘接管、终端关闭后旧卡片失效。当前识别 Claude 英文信任菜单。用户主目录的信任可能仅保留本次启动，建议通过 /new 项目名 进入项目子目录。

Claude 运行中的交互通过官方钩子接入：PermissionRequest 显示命令/工具参数，企微“仅允许本次 / 拒绝本次”返回本次决定；PreToolUse 匹配 AskUserQuestion，按问题逐题展示选项卡片，支持单选、多选、取消及自定义文本。普通回复用于当前聚焦会话的待回答问题；跨会话可用 `/回答 问题编号 内容`（编号随问题发送）。多选点击选项后再提交，也可回复 `1,3`。4 分钟未完成、本机键盘接管、停止或关闭时取消未完成交互。仅本次启动参数加载钩子，不设置永久批准规则。新版需要重新进入 /claude 后生效。

固定采用简洁进度，无档位设置。20 秒内结束的任务不发进度；长任务首条进度至少等待 20 秒，此后间隔至少 30 秒且内容变化才发。Claude 根据真实工具事件显示阶段，不含命令参数、输出和内部思考；其他 CLI 没有阶段事件时只提示仍在执行。等待审批/追问、限流重试时暂停普通进度。进度卡片支持查看状态和停止本次，绑定原会话和本轮任务，旧按钮不能中断新任务。消息过滤常见令牌、密码和私钥格式，但不能保证识别所有自定义敏感数据。

附件发送：企微启动的 Claude / Codex / CodeBuddy 会获得会话专属 MCP 工具 `send_file_to_wecom`，内置 AI 的企微会话也提供同名工具。用户要求发送文档、图片或网页截图时，Agent 自行生成文件/完成截图，再传入本机绝对路径。应用上传文件并只向该会话账号发送 file 消息；图片按可下载文件发送，不转成终端文字。单个文件最大 50 MB，不支持目录、空文件或仍在变化的文件。远程 SSH 文件需先下载到本机。发送工具不接受接收人参数；同轮相同文件去重，关闭/停止任务后不继续投递，发送状态不确定时提示检查企微而不自动重发。此功能为向企微发送附件，不包含从企微下载用户上传文件。MCP 通过 CLI 启动参数临时载入，不更改用户全局 MCP 配置。
