# 1.0.4 代码 Review 与改动清单

日期：2026-10-23。范围：当前工作区，包含此前尚未提交的企微、Claude 与桌面宠物修复。本轮未提交、推送或发布 Release。

## 本轮新增功能

- 新增“设置 → MCP 管理”，支持标准 `mcpServers` JSON 编辑、示例、服务器启停和未保存修改提醒。修改服务器条目即可增删配置。
- 支持 stdio / HTTP / SSE 基础配置，验证服务器名称、参数、环境变量、URL 和请求头，保护企微附件工具保留名称。
- 配置通过 Windows 安全存储加密保存。仅管理页面主动打开时读取明文；保存失败会回滚。
- FanBox 管理的本地 Claude 快捷启动、历史恢复、定时任务和企微 `/claude` 加载启动时快照，不改写全局 Claude 配置；企微附件 MCP 继续合并加载。
- 每个启动过程使用自己的临时文件；终端关闭、启动失败和正常退出时清理，修改配置不会影响已启动的会话。
- 已按用户要求将软件版本升级为 1.0.4，更新 README、用户指南、离线指南和 CHANGELOG。

边界：手动在 shell 输入命令、远程 SSH、Codex 和 CodeBuddy 暂不自动注入软件 MCP。命令已显式指定 `--mcp-config` 时保留调用者配置。OAuth / headersHelper 等扩展字段暂不支持；界面会给出不支持字段的提示。进程强制终止或机器断电无法保证执行正常退出清理。

## Review 发现并修复

| 问题 | 影响 | 修复与验证 |
| --- | --- | --- |
| SSH 配置保存/删除、AI 配置保存/删除缺少完整失败回滚 | 文件写入失败后，内存配置、凭据、活动模型或权限状态仍变化，与磁盘不一致 | 更新前保留旧值，失败时还原；SSH 凭据先复制再修改；注入写盘失败的回归测试通过 |
| 主窗口允许部分非 HTTP 新窗口，缺少工作台导航限制 | 工作台可能被本地预览或外部页面替换，扩大带有桌面能力页面的可访问范围 | 子窗口统一拒绝；主窗口仅保留工作台地址，外部网页交由系统浏览器；真实 Electron 隔离测试通过 |
| CLI 结果通道重复关闭不安全，退出时清理不完整 | 重复关闭可能读取已删除目录；部分临时配置未及时清理 | 关闭操作可重复调用，退出时关闭 CLI 通道及 MCP 快照；相关回归通过 |
| 剪贴板写入没有成功反馈检查 | Windows 拒绝写入时可能错误报告复制成功 | 写入后核对、有限重试、持续失败时提示；模拟占用/恢复测试及新版真实复制/粘贴测试均通过 |
| 生产依赖 `ip-address` 10.2.0 存在已知高危漏洞 | 代理依赖链中的地址解析可能不符合安全预期 | 在现有依赖兼容范围内更新到 10.7.4；SSH/代理相关回归通过；`npm audit --omit=dev` 为 0 个已知漏洞 |
| Electron、构建工具与编辑器依赖存在安全告警 | 完整依赖审计初次报告 35 项，包含 Electron 高危和构建链 tar 严重告警；仅查生产依赖会漏掉随软件交付的运行环境 | 升级 Electron 42.11.18、electron-builder 26.15.3、@electron/rebuild 4.2.1，升级兼容依赖并重建编辑器，对数学扩展定向使用 KaTeX 0.19.0；完整依赖审计为 0 |
| 打包期间文件变化可导致 ASAR 文件索引偏移 | 生成的文件存在但内容损坏，普通构建成功不能证明包可运行 | 增加逐文件 SHA256 校验并接入最终 EXE 元数据处理；正常包与损坏包回归通过，冻结源码后重建验证 |
| 部分旧测试夹具不符合现有软件行为 | 未提供安装包路径、SSH 系统检测默认关闭、中文窗口标题编码、后台页面节流等引发误报 | 补充独立开发启动回退、明确启用检测、设置测试输出编码与后台运行参数；相关界面测试复测通过 |

开发环境要求 Node.js 22.12 或以上。软件版本仍为用户指定的 1.0.4。内核升级增加了基础运行文件体积，体积优化将以新版安全内核为基线，不回退安全补丁。

主要修改位置：`electron/mcp-manager.js`、`public/mcp-settings.js`、`electron/cli-result-channel.js`、`electron/remote-workspace.js`、`electron/remote-store.js`、`electron/main.js`、`electron/preload.js`、`electron/clipboard-text.js`、`public/app.js`、`public/index.html`、锁文件、相关测试和文档。
