OVERVIEW / 平台总览
一个工作台，组织全部开发入口
fanbox-pro 是运行在 Windows 桌面的本地开发工作台：把文件、AI、远程机器、代码仓库与定时任务集中到一个窗口，左侧导航即工作地图。
06核心模块

📂文件与编辑

快速入口管理常用目录；内置编辑器渲染 README / Markdown，配合 AI 与终端即改即验。

打开项目 3 秒内可见，文档即门面

🤖AGENT 项目

为每个项目建立 代码空间（automelt2、team-space、rs-hiveforge…），记录任务、会话与 README，多项目并行不串线。

项目上下文统一归档，随时续接

🖥️SSH 连接

会话管理 + 长连接，支持 TAU、跳板机、多终端标签；在远程机器上直接发起 AI 对话操作。

远程机器像本地目录一样触手可及

🌿GIT 仓库管理

多代码空间仓库目录统一列出分支、领先/落后与工作区状态，右键完成切分支、拉取、推送、合并、删除。

几十个仓库一屏总览，批量同步

⏱️定时任务

定时执行 Claude Code 或本地脚本：每日提交代码 Review、仓库定时同步、巡检报告全自动跑。

重复劳动交给计划，人只看结果

🐾宠物与企业微信

桌宠显示 企业微信在线状态与自定义玩法；企业微信接入终端，在聊天里远程操作 CLI 与任务。

离开工位后，机器仍在被指挥

01FILES

📁文件树 + 渲染视图

⚡即改即验

下方内嵌 AI 会话与终端，看到构建命令后可以直接执行验证，阅读—修改—运行不离开窗口。

接手新项目：打开目录 → 读 README → 跑命令，一屏完成

MODULE 02 / GIT 仓库管理
多代码空间仓库目录处理
02REPOS

📋全仓一屏总览

所有代码空间的仓库列表集中展示：当前分支、领先/落后、工作区状态一目了然，支持按名称过滤与列排序。

🖱️右键即操作

右键菜单覆盖日常 Git 动作：切分支、拉取、推送、合并、 stash、检查冲突、删除，并支持多仓库批量同步。

以前逐仓开终端敲命令，现在一屏点完

MODULE 03 / GIT 自动同步
工作目录 Git 分支定时同步
03SYNC

🔄计划驱动同步

按名称 + 动作 + 频率配置同步计划（如"全仓库同时拉取，每日 8 点"），启用后自动在后台执行，无需人守。

🧾执行留痕

每次执行写入历史记录，成功失败可回溯；同步策略避免打断未提交的工作区。

分支永远新鲜，第二天开工不用先拉一遍
自动同步计划与执行记录 · 点击查看大图
MODULE 04 / 定时任务
定时执行 Claude 或本地脚本
04CRON

🧠Claude 计划任务

任务绑定项目目录，定时唤起 Claude Code。例如"每日 7:30 提交前代码 Review"，AI 逐仓检查 merge 冲突、字段变更、空指针风险并产出结论。

📜本地脚本同样支持

巡检、备份、报表等脚本纳入同一调度；最近 10 次执行记录可直接点开查看完整输出。

重复性检查全自动跑，人只看结论

MODULE 05 / SSH 连接
SSH 登录长连接
05REMOTE

🔌会话管理与长连接

机器信息集中管理，会话保持长连接不频繁掉线；支持 TAU、跳板机等链路，自动重连。

同一窗口打开多个终端标签：本地 PowerShell、远程 bash 并行操作，布局可调，配合 AI 面板一起用。

远程机器挂成一排，随点随用

MODULE 06 / SSH × AI
SSH AI 对话操作机器
06AI-OPS

💬对话即运维

在远程机器上直接与 AI 对话："看下当前并发到多少了"，AI 自动执行命令、读取输出、汇总结果，无需自己拼一长串 shell。

🛡️可确认可回看

AI 给出的计划与待办先确认再执行；整个过程留在会话里，事后可回溯当时跑了什么。

运维经验沉淀成对话，新人也能上手查线上

MODULE 07 / 企业微信集成
企业微信接入终端
07WECOM

📲聊天里指挥机器

企业微信接入本地终端：在聊天窗口发消息即可操作终端与各类 CLI，查看任务状态、继续某项工作、选择待办下一步。

🔔结果回推

任务执行完成后状态回推到聊天（如 agent 任务完成通知），人在外也能跟进进度、随时下发新指令。

离开工位 ≠ 停工，机器仍在被指挥

MODULE 08 / 宠物板块
宠物板块 · 企业微信状态与玩法
08PET

🐾状态可视化

桌面宠物实时显示企业微信在线状态（在线时段、离开时长等），工作状态一眼可见。
